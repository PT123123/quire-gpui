## 组合输入（composition）
- [x] 拼音输入正常上屏（微软拼音 / 搜狗均可）
- [x] 组词过程中候选窗位置跟随光标（不漂移到屏幕角落）
- [x] 组词中按 Backspace：删除的是拼音字母，不是已上屏文字
- [x] 组词中按 ←/→：光标在拼音串内移动，不拆散已输入文字
- [x] 组词中途按 Enter：字母原样上屏（不是候选词）
- [x] 中英混排：切英文再切回，光标位置不跳

## 编辑操作
- [x] 句中点击定位准确；拖选一个词后直接打字 = 替换
- [x] Ctrl+A 全选本块 → 打字覆盖 → Ctrl+Z 恢复整段
- [x] 行首 Backspace 合并到上一段（合并后光标在接缝处）
- [x] Enter 从句中拆块（后半句成为新块并获得焦点）
- [x] 中文段落末尾 Enter 新块；空块 Enter 连续出新块
- [x] Ctrl+Z / Ctrl+Y 跨这些操作不丢字、不重复

## 中文与富文本
- [x] 中文选区 Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+E 行内代码（失焦后样式可见）
- [x] 中文选区 Ctrl+L 加链接，Apply 后链接变色、点击能打开浏览器
- [x] 导出的 .md 中中文与格式标记无损（Import/Export 面板命令）
