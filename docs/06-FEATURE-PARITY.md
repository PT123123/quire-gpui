# 功能追踪与遗漏审计

实施时创建 `docs/PARITY.csv`，每个独立用户动作一行。列建议：ID、区域、入口、旧版 source:line、预期行为、UI 状态、core action、持久化、undo、快捷键、截图场景、测试/人工步骤、实现状态、验证状态、差异。

状态区分未开始/实现中/已实现/已验证/阻塞/经用户确认延期。实现状态与验证状态分列。不能以“已有按钮”“已连接回调”标记整个功能验证完成。

## 必须展开的功能族

1. 窗口：启动参数、打开库、尺寸/位置、拖动、缩放、最小化、最大化、关闭、托盘退出。
2. 导航：固定入口、树、展开、收藏、最近、创建、重命名、深复制、移动、删除、确认与 fallback 页面。
3. 页面：图标、封面、字体、全宽、小字号、锁定、模板、历史、恢复、分享/链接等实际入口。
4. 编辑：所有块、键盘结构命令、marks、剪贴板、Markdown、slash、菜单、拖动、undo/redo、查找。
5. 内容：附件导入/引用/缩略图/原图/删除恢复、表格、分栏、引用、代码、数学、TOC、embed、synced、backlink。
6. 数据库：属性 CRUD、列类型、编辑、视图 CRUD/切换、过滤、排序、分组、公式、relation、rollup；每个视图单列。
7. 整理：笔记与任务 CRUD、标题/正文/标签、日期/优先级、子任务、清单、智能视图、列表/平铺、选择/多选/批量/复制、拖动、撤销条、标签包含/排除/建议。
8. 搜索：FTS 查询、中文、空查询、异步结果、跳转、命令过滤、键盘操作。
9. 设置：每个实际可修改设置及持久化、搜索匹配、主题目录、system、快捷键冲突、about 可复制信息。
10. 同步：设备发现、识别、状态、握手/协议拒绝、双向修改、冲突、失败与重试。
11. MCP：当前工具目录、权限、启停、状态和修改后 UI 刷新。
12. 桌面：Alt+N/Alt+M、独立速记、共享草稿、托盘菜单、单实例（若旧版支持）、系统打开文件/URL。
13. 可靠性：保存失败、只读、损坏库、恢复通知、退出 flush、日志、崩溃恢复、未知设置/kind。

## 三次覆盖审计

第一次扫描 ui/Types.slint 所有 callback、AppWindow 根 popup 和每个组件入口，确认矩阵都有对应项。第二次扫描 controller.rs 回调注册、state.rs public 方法、MCP actions，识别只有代码而无页面描述的能力。第三次扫描截图 apply_scene、旧版 SPEC 和近期未提交修改，确认新加入功能没有丢失。

自动索引仅用于发现候选，不能证明所有 callback 对应用户功能；需要人工确认真实可达路径与权限条件。

## 差异记录

建立 DIFFERENCES.md：差异 ID、旧行为、新行为、原因、是否用户确认、数据影响、视觉证据、回归测试。已知 Slint 富文本限制的修复应记录为改善，不能偷偷改成新的内容模型。没有确认的功能删减仍是缺口。
