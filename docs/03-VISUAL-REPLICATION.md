# 逐页界面复刻规格

本文件说明必须呈现什么；精确坐标与全部细节以 reference/slint-desktop/ui 及同条件实拍为准。实现开始前为每个界面建立默认、空、选中、hover、编辑、错误和窄窗口状态参考图。不能只对齐默认画面。

## 1. 主窗口与顶栏

无边框自绘窗口，40 逻辑像素顶栏。保留侧栏开关、面包屑、页面操作及右侧最小化/最大化/关闭；拖动区域不能吞掉按钮。双击顶栏、最大化/还原、边缘缩放、Windows Snap、多屏 DPI 按真实 Windows 行为验收。

库恢复/保存异常提示带位于顶栏下方，参考高度 30px；出现时不能挤掉侧栏底部入口。主内容由左侧 sidebar 和右侧 Editor 或 OrganizerArea 组成。切换区域时输入路由只到当前区域，焦点和待保存草稿正确处理。

## 2. 侧栏

背景为主题 elevated surface，不把文档渐变重新铺进侧栏。复刻工作区头部、固定入口、收藏、最近、工作区页面树、添加页入口、底部版本/设置等实际内容。顺序与文案读 Sidebar.slint。

固定行参考高度 28px、图标槽 16px，字号 13px；page tree 缩进、展开箭头、页面 emoji、选中背景、尾部菜单、内联重命名均按源码。侧栏展开宽度使用持久化值，默认/最小/最大限制读 state.rs 和 Sidebar.slint，不凭经验猜测。

支持拖宽、折叠、恢复宽度、长标题省略、右键菜单、树展开收起；折叠动画不保留透明但可点击的区域。页面右键菜单需覆盖新子页、重命名、复制、收藏、移动、删除等当前动作。

## 3. 文档页

主文档内容最大宽度 760px，标准边距 token 96px；窄窗口实际约束与全宽模式按 Editor.slint 计算，不将 760+192 固定为所有窗口最小宽度。顶部无封面时 hero spacing 为 64px。页面标题 38px，页面图标 46px，标题与第一块的间隔按现有公式。

封面参考带高 168px、标题重叠量 68px；图像 cover 裁切，标题位于封面下缘内部。覆盖纯白图片也可读的黑色遮罩 #0000009e；图标/标题增高后封面下边界需随内容延伸，不能让白色标题落到浅色页背景。

页面字体默认/serif/mono、小字号 0.87、全宽、锁定、页面图标/封面、模板、历史版本入口全部保留。页面级字体只影响文档，不缩小 sidebar/菜单/设置。

块首手柄、加号、缩进、列表标记、待办勾选、引用线、callout、代码背景、分割线和块色要与旧版一致。长段落允许正确折行，不把旧版裁切当作必须复制的视觉。尾部空白、点击尾部新建块、backlink 面板也属于复刻范围。

## 4. 菜单、搜索与命令面板

搜索 Ctrl+P：空查询最近项，查询后标题/正文结果、命中摘要、键盘导航与跳转。命令面板 Ctrl+K：命令过滤、键盘选中、执行后关闭。页内查找 Ctrl+F：输入、计数、前后命中、滚动定位和选区/命中高亮。

slash 菜单与块手柄菜单在窗口层绘制，不能被后续块覆盖。块菜单基准宽 176px、行高 28px、外侧 padding 4px（AppWindow.slint）；其他菜单不可套用同一尺寸，逐个读取。

保留标题/图标/快捷键提示、分隔线、危险色、禁用态、颜色点、二级列表。弹层靠近右下边界时翻转或夹紧；键盘选中保持可见。Escape 只关闭最上层，外点关闭不穿透触发底层删除或跳转；关闭后返回原输入焦点与选区。

确认对话框、设置、链接编辑是模态遮罩类；普通锚定菜单无全页变暗。遮罩色 #00000059。不能为“高级感”给所有菜单增加整页黑幕。

## 5. 整理区 Organizer

复刻原有卡片化工作面与列布局：导航/标签列在最右侧，不能按一般应用习惯移到左边。详情、列表和导航的顺序/宽度以 OrganizerArea.slint 实际布局为准。

笔记/任务 tab；收集箱、今天、近七天、全部、已完成等实际智能视图；任务清单颜色；标签树、包含与反向排除；添加顺序/优先级/截止日期排序；列表/平铺切换。

笔记行标题、摘录、标签、时间、选中态；任务行完成框、标题、优先级、到期信息、子任务计数、操作菜单；详情字段、可编辑草稿、日期输入、子任务编辑等逐一复刻。导航行参考高度 34px，详情信息行参考 22px。

多选模式替换工具栏，显示已选数量、全选/取消、复制/完成/删除和退出。笔记 ID 和任务 ID 使用类型隔离，不共享裸整数集合。批量动作一步撤销，离开区域按旧版退出多选。

延迟删除撤销条浮在窗口右下，参考 380×46px，距右/下各 24px；不挤压主内容，跨区域仍可撤销。超时提交必须按旧版语义执行；窗口关闭时待删除批次的处理要明确。

## 6. 笔记撰写与独立速记

NoteCaptureCard 同时用于整理页撰写浮层和独立速记窗口。复刻文本框、占位符、标签建议、发送/保存、取消和关闭。草稿未提交不能提前创建空笔记；取消/Escape/关闭不得写库。

速记窗口：默认 560×340，最小 360×220，无框、置顶、顶部可拖动、隐藏任务栏项；位置、多屏边界按旧版平台实现核对。Alt+N 打开速记不恢复主窗口、不切主窗口区域、不覆盖主页面 selection。保存成功才清草稿并收起；保存失败保留输入和错误。窗口独立绘制同主题渐变。

## 7. 数据库界面

DatabaseView/Cell/Switcher 与所有 Database*Popup 均为范围内。表格：表头、列类型图标、行、滚动、选择、编辑态和列配置；看板：列头、计数、卡片、拖放反馈；画廊：卡片网格；日历：日期与记录；表单：字段输入和提交。每个视图对齐源码真实支持能力。

过滤/分组/公式/relation/rollup/属性选择弹层需有配置中、空结果、错误、禁用态截图。不能只复制外观后将全部动作映射成无效回调。

## 8. 设置、同步、MCP、关于

SettingsDialog 的实际 tab/入口和搜索关键词逐个扫描，不仅相信文件首部“五 tabs”注释。主题卡 110×62px、圆角 8px，卡片自身使用该主题渐变和文本色；选中边框 2px，普通边框 1px。

对话框宽 560px 固定（`ui/components/SettingsDialog.slint:327`），tab 由一个整数 `settings-tab` 选（0 外观 / 1 通用 / 2 同步 / 3 MCP / 4 快捷键 / 5 关于）。逐 tab 参考图见 `reference/shots/t-light__tab-*.png`；注意旧版同步页与 MCP 页的右侧内容超出对话框表面、被硬裁且不出省略号（`docs/14-REFERENCE-SHOTS.md` 第 5 条），照抄前先决定是否修。

外观：system 与 12 主题、当前选中；通用：实际存在的保存/桌面行为设置；快捷键：文案、启停、冲突反馈；同步：设备发现、状态、进度、失败和重试；MCP：实际开关、权限/状态/信息；关于：版本、真实 renderer、可复制路径/信息。

版本历史面板、图标选择器、链接编辑、确认删除等不能遗漏。空数据时应呈现真实空状态，不能留开发占位字样。

## 9. 公共视觉检查

每个控件核对：默认/hover/pressed/selected/focus/disabled；鼠标命中范围与像素一致；长中文和英文省略；emoji 字体；滚动条、边界裁切、层级和阴影；键盘入口。图标优先转换现有 Icons.slint 的矢量路径，不以另一套图标替换。
