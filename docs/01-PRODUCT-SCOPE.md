# 产品范围与复刻原则

## 产品定位

Quire 是本地优先的 Rust 桌面文档工作区，包含 Notion 式块编辑器、页面导航、结构化数据库、笔记/任务整理、局域网同步和桌面速记。Windows 是首要平台；Android 继续使用现有 Compose 壳，共享 core。

本次是桌面 UI 技术迁移。文档不是要求“从零重做一个类似 Notion 的应用”，而是要求重建现有 Quire。现有操作路径、数据语义、主题和页面信息密度是约束。

## 参考优先级

1. 用户在当前任务及后续任务的明确要求。
2. 冻结源码对应的真实可运行行为、同条件截图和交互录像。
3. 冻结源码中的 UI 和 Rust 控制器/状态实现。
4. 旧版 docs/SPEC.md、DECISIONS.md 与功能说明。
5. 本交接包的概括与建议。

旧版 PLAN/README 含历史阶段记录；不能把早期“未实现”当作当前缺失，也不能把文档中的完成声明当作已经验证。SettingsDialog 的开头注释、颜色文件的平面主题计数等可能落后于实际代码，必须核实。

## 什么必须相同

- 全部主要区域、面板顺序、文案、入口和层级。
- 当前 12 个 theme ID、名称、顺序、颜色、4 套渐变和 system 解析语义。
- 字体层级、内容宽度、边距、侧栏和顶栏、主题卡、封面与图标。
- 快捷键、选中态、hover、焦点、菜单关闭、拖放落点、撤销粒度。
- 页面/块/属性稳定 ID、命令语义、存储格式、附件引用和同步协议。
- 真正持久化、真实搜索、可撤销修改、正确的错误反馈。

## 什么可以改善

旧版明确记录的富文本裁切、编辑时样式消失等框架限制，可以在 GPUI 中修复。改善不得改变文本内容、mark 范围、快捷键、用户操作语义或主题风格。

内部结构可重构：使用 typed action、实体状态和增量投影代替巨型回调注册及 Slint binding。每个可见差异写 `docs/DIFFERENCES.md`，解释旧行为、新行为、理由与验收证据。该文件由实施阶段在新项目里建立，本交接包中没有旧版同名文件可参考。

## 不自动扩大的范围

不新增云服务、多人协作、AI 功能、插件市场；不更换核心存储，不重写同步协议，不改 Android UI，不重新命名主题。不把网页或 WebView 当作编辑器替代方案。

## 交付级别

- 技术验证：只证明关键能力可以成立。
- 可用预览：覆盖部分实际工作流，明确缺口。
- 完整复刻候选版：功能矩阵全覆盖，通过视觉/交互/数据/平台验收。
- 正式切换：用户确认候选版后另行执行，需备份和回退路径。
